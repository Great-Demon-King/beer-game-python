# 啤酒游戏（Beer Game）供应链模拟软件

基于 Python 开发的供应链啤酒游戏模拟软件，用于演示和体验供应链中的**牛鞭效应**：终端客户需求的小幅波动，经过多级订货后会被逐级放大。

> 本项目为学习供应链管理课程期间的个人项目，开发过程中借助 AI 编程工具辅助，我负责需求设计、规则与成本模型设定、测试与调试。

## 项目背景
供应链各环节信息不共享、订货存在提前期，容易造成库存积压或缺货。
本项目通过程序模拟这一过程，帮助理解库存与订货决策的影响。

## 主要功能
- 模拟 [零售商 → 批发商 → 分销商 → 制造商] 的 [四] 级供应链
- 可设置：需求规律（[固定 / 随机]）、订货与运输提前期、初始库存、库存成本、缺货成本
- 按周期模拟订货、发货、库存更新
- 自动统计各级库存、缺货量和总成本
- [结果可视化：订单波动逐级放大的曲线图]
- [支持不同订货策略对比：如基本库存策略、信息共享]

## 规则与成本模型
- 每周期流程：收货 → 满足下游订单 → 决定本期订货量 → 下达订单
- 成本 = 库存成本 × 期末库存 + 缺货成本 × 缺货量（[单位成本为多少]）
